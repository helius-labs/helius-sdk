    Interface ParsedEventsClient

    Parsed Events API client interface

    Parses transaction signatures or address history into decoded instructions, transfers, and summaries using Helius's IDL catalog, and scans address history server-side by program instruction or token mint. Successor to the Enhanced Transactions API (helius.enhanced). Mainnet only.

    Example

    import { createHelius } from "helius-sdk";

    const helius = createHelius({ apiKey: "your-api-key" });

    const [result] = await helius.parsedEvents.parseTransactions({
      transactions: ["..."],
    });

    const history = await helius.parsedEvents.getTransactionHistory({
      address: "...",
      limit: 50,
    });

    const matches = await helius.parsedEvents.scan({
      address: "...",
      match: { mints: [{ mint: "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v" }] },
    });

    scan

    • scan(
          params: ScanParsedTransactionHistoryRequest<"count"> & {
              returnShape: "count";
          },
      ): Promise<ScanCountResponse>

      Scan an address's history server-side for transactions that call any of match.programs (optionally specific instructions), touch one of match.mints, or both (when both are set, both must match). By default an instruction or balance only counts when it involves the scanned address; scope: "transaction" on an entry counts it anywhere in the transaction (see ScanMatchScope). The native SOL pseudo-mint So11111111111111111111111111111111111111111 matches lamport changes, not counting the fee (see ScanMintMatch). Only successful transactions are scanned unless status is "any" or "failed". returnShape returns the parsed matches (transactions, the default), their signatures (signatures), or only scan.matchedTransactions (count). Paginated with paginationToken; keep going while one is returned, even when data is empty. Costs 10 credits plus 1 per history page scanned.

      Parameters

      • params: ScanParsedTransactionHistoryRequest<"count"> & { returnShape: "count" }

        Address, match criteria, return shape, budget, and pagination options

      Returns Promise<ScanCountResponse>

      The matches for the returnShape, the next paginationToken, and a scan summary (stoppedOn, matchedTransactions, creditsCharged)

      Throws

      Error on a request-level failure: Helius HTTP 400 for an invalid body or match, auth or rate-limit errors, or Helius HTTP 503 when at capacity or the first history page missed the request time limit
